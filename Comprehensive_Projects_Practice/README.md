随笔:

这门课如果想水,一定是一门特别好水的专业课.你可以加入一个大佬所在的小组,然后大佬一个人全栈开发,其余人稍微写写文档就行了.找不到大佬也可以小组几个人凑钱淘宝上买个大学生毕设项目交上去,还可以B站找点网课,比如拿黑马程序员的一些外卖项目直接交上去.然后在结课的时候你会发现那些网上买的,B站上面抄的项目,由于前端做的精美,PPT做的好看,反而得分会比你自己认认真真学个一学期写出来的东西高.但是不要灰心,这门课可能是大学四年专业课中对你找工作最有帮助的一门课了(前提是得自己认认真真写),尤其是对于到了大三还没有实习经历和项目经历的人来说,这门课是很有帮助的

希望能看到这份随笔的人可以认认真真搞一份对的起自己的综合项目实践,而不要在学院要求的毕业实习面试的时候,技术面随便问几个简单的问题就G了
